## What the 10 Face reacquisitions establish

The retained `01-480p-4x3/summary.json` for `face-yuv-guarded-one-20261014-1` records a valid **30.035 s counter window**, 290 Face callbacks, 270 callbacks with a face and 270 valid 478-point outputs. Thus 20 completed callbacks had no face. The window has 260 comparable adjacent detected bounding-box pairs, zero disjoint pairs, 10 reacquisitions and zero pipeline errors. Face completion rate was 9.655 Hz. This is a completed **collection**, not proof of uninterrupted tracking.

`FaceContinuityProbe.observe` increments reacquisitions exactly once when a non-null Face bounding box follows one or more null Face callbacks after a previous non-null box. The counter therefore confirms **10 detected → missing → detected episodes** within the measured window. `TaskSources.kt` maps an empty MediaPipe Face landmark result to a null Face; successful callback validation requires 478 points, a valid bounds box and matching timestamp. `MediaPipePipeline.kt` feeds that box to the probe after a valid callback. The zero error delta rules out *reported* result-invalid, runtime, submit and watchdog errors in this window. No separate application confidence filter is applied to these successful Face callbacks. MediaPipe's internal detection/tracking/confidence decision is not exposed by these counters.

**Confirmed:** intermittent Face landmark absence, later detection return, no overlapping-pair disjoint jump, no reported pipeline error, and four sampled local stills with landmarks on the principal visible face. **Hypotheses only:** head movement/occlusion, distance/framing, lighting, and MediaPipe internal tracking resets or confidence rejection. Bounding-box overlap tests landmark detection continuity only; zero disjoint pairs neither proves identity continuity nor excludes jumps across a null gap.
